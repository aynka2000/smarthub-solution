IVANS (Insurance Value Added Network Services)

IVANS is the insurance industry’s exchange solution that connects insurers, MGAs, agencies, and insurance products. This eliminates time spent manually managing paperwork and requesting information from individual insurer partners. IVANS Download automates the exchange of critical policy-related details to ensure the most up-to-date information is instantly available when you need it.

IVANS has a conversion tool that converts Duck Creek session data to AL3 format then to DAT format for further processing. The tool that converts each insurer’s Duck Creek session data to AL3 will cost the insurance company significant money. As it’s not one product fits all solution, each insurer will have their own custom session XML data, and it will change per LOB, so you will be charged significantly to do that customization.

We have helped many insurers by solving this problem by giving a customized solution for 1/10th the cost. We also help the customer maintain the conversion from session to AL3 and DAT format for multiple LOBs. Furthermore, we provide conversion source code and documentation, so you can save costs and maintain internally in the long term.

But if you need a hands-free solution, we will help maintain it for the long term at a low cost.
